# Solar System Explorer

An interactive, animated dashboard built entirely in Python using the Flet framework. Explore the planets of our solar system with real astronomical data and smooth UI morphing effects.

## Features

* **Smooth Animations:** Features a dynamic "virtual planet" that seamlessly morphs in size and color when you switch between celestial bodies.
* **Real Astronomical Data:** Includes accurate statistics for all 8 planets, such as distance from the Sun (AU), mass relative to Earth, surface gravity, and a brief description.
* **Modern UI:** A clean, deep-space dark theme with organized data cards and a polished layout.
* **Cross-Platform:** Runs as a native desktop application or a web app with zero code changes.

## Tech Stack

* **Language:** Python 3.x
* **UI Framework:** Flet like Builds interactive web, desktop, and mobile apps in Python without prior frontend experience.

## How to Run Locally

 **Clone or Download the Project:**
   Save the `space.py` file to your local machine.

 **Install Dependencies:**
   Ensure you have Python installed, then install the required Flet library using pip:
   ```
   pip install flet
   ```
